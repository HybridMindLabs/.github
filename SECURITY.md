# Security Policy

## Reporting a Vulnerability

If you believe you've found a security vulnerability in HybridCore or any
HybridMind Labs extension, please report it privately — **do not open a
public issue**.

Email **[support@hybridmarket.org](mailto:support@hybridmarket.org)** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce (proof-of-concept code or requests, if applicable)
- The affected repository and version

We aim to acknowledge reports within 48 hours and to keep you updated as the
issue is investigated and resolved. Once a fix ships, we'll credit you in the
release notes if you'd like — just let us know.

## Supported Versions

Only the latest released version of HybridCore and each extension receives
security fixes. Sites should stay current — `php artisan hybridcore:update`
keeps core and enabled extensions on the latest release.
